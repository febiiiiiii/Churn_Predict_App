📉 Customer Churn Prediction

Model machine learning untuk memprediksi apakah pelanggan telco akan berhenti berlangganan (churn), lengkap dengan web app interaktif untuk mencobanya.

🔗 Live Demo: churnpredictapp-mhmixcfrbpnu5psn3fz5ha.streamlit.app

Hasil

Model Logistic Regression dipilih sebagai model final (accuracy 80%, ROC-AUC ~0.8) setelah dibandingkan dengan Decision Tree dan Random Forest. Faktor paling berpengaruh terhadap churn: tipe kontrak bulanan, tenure rendah, dan layanan internet fiber optic.

Tech Stack

Python, pandas, scikit-learn, Streamlit
